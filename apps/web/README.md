# Neuroset Web

Статический веб-чат с OpenAI-совместимым API `/chat/completions`. Работает на GitHub Pages без собственного сервера. Интерфейс на русском, React + TypeScript + Vite.

## Локальный запуск

Нужен Node.js 24 LTS.

```powershell
cd apps/web
npm ci
npm run dev
```

Откройте адрес, который выведет Vite (обычно `http://127.0.0.1:5173`).

Для проверки готовой сборки:

```powershell
npm run build
npm run preview
```

## GitHub Pages

1. Загрузите проект в репозиторий GitHub. Файл `apps/web/package-lock.json` должен быть в репозитории.
2. В **Settings → Pages → Build and deployment → Source** выберите **GitHub Actions**.
3. Отправьте изменения в `main` / `master` или запустите **Actions → Web · GitHub Pages → Run workflow** для основной ветки.
4. После успешного задания `deploy` сайт будет доступен по адресу `https://<username>.github.io/<repository>/`. Точная ссылка появится в задании и разделе Pages.

Workflow проверяет тесты и собирает только веб-приложение. Для основной ветки с другим именем измените `branches` в `.github/workflows/pages.yml` или запускайте workflow вручную. Пути к ресурсам относительные, поэтому работают и домен пользователя, и подпапка репозитория. Содержимое `dist` также можно разместить на любом статическом HTTPS-хостинге.

## Подключение API

Нажмите **Подключить модель** или **Настройки**:

- **Адрес API**: например `https://api.openai.com/v1`. Допускается полный адрес `https://provider.example/v1/chat/completions`; префиксы провайдера сохраняются.
- **API-ключ**: ключ провайдера. Можно оставить пустым, если API не требует авторизации.
- **Модель**: точный ID модели. Кнопка **Загрузить** получает список через `GET /models`; ручной ввод работает независимо от поддержки этого метода.
- При необходимости задайте системную инструкцию, температуру, `max_tokens` и режим потоковых ответов. Пустые числовые поля не передаются в API.

Приложение отправляет `POST /chat/completions` с `model`, `messages`, `stream`, а при включённых функциях — `tools` и `tool_choice`. История текущего чата и пары `assistant/tool` передаются как контекст. Поддерживаются SSE (`text/event-stream`) и обычный JSON. Цикл ограничен 10 действиями и 3 ошибками; кнопка остановки отменяет запрос, а незавершённый ответ остаётся в истории. Максимальное ожидание полного ответа — 10 минут.

## Инструменты обычного чата

Инструменты не дают модели доступа к проекту, диску или командной строке. Они работают только для текущего сообщения и запускаются через стандартные function/tool calls выбранной OpenAI-совместимой моделью.

- **Поиск в интернете** — через Tavily Search. Укажите ключ `tvly-…` в **Настройки → Инструменты → Ключ поиска Tavily**. Результаты и URL показываются в раскрываемом блоке действия, а модель получает заголовки, ссылки и краткое содержание для ответа с цитированием. Ключ Tavily не передаётся LLM API.
- **Чтение ссылок** — через Tavily Extract при наличии ключа Tavily или Jina Reader без ключа. Разрешаются только общедоступные HTTP(S)-ссылки; localhost, IP-адреса, внутренние домены и URL с логином/паролем блокируются. Страница считается недоверенным источником данных и не может менять инструкции модели.
- **Python** — через Pyodide, загружаемый с jsDelivr при первом использовании. Запуск происходит в sandboxed iframe и отдельном worker; сеть, localStorage/IndexedDB, файлы и терминал недоступны. Доступны стандартная библиотека и пакеты Pyodide, включая NumPy, pandas, SymPy и matplotlib. `print()` попадает в результат, matplotlib-графики показываются как изображения. Каждый вызов запускается в чистом окружении и ограничен двумя минутами.
- **Дата и время** — локальное время для указанной IANA-зоны, например `Europe/Moscow` или `UTC`.

Инструменты можно отключать кнопками **Интернет** и **Python** рядом с полем ввода. Если включена генерация изображения, обычные инструменты на этот ход не выдаются: модель получает принудительный вызов `image_generation`.

## Генерация изображений

Рядом с композером находится кнопка **Создать изображение**. Она доступна, когда выбранная модель или список `/models` содержит GPT Image-модель (`gpt-image-2` имеет приоритет, затем другие `gpt-image-*` и `chatgpt-image-latest`). Можно указать модель вручную в **Настройки → Инструменты → Модель изображений**.

1. Нажмите кнопку изображения — разрешение действует только для следующего сообщения.
2. Опишите желаемую картинку обычным языком и отправьте сообщение.
3. Модель один раз преобразует запрос в технический промпт с композицией, освещением, стилем, `filters` и `negative_filters`, после чего интерфейс вызывает тот же API через `POST /images/generations`.

Отправляется `n: 1`, выбранные `size` и `quality`, `output_format: png`. Ожидается ответ `data[0].b64_json`; PNG проверяется и сохраняется в IndexedDB браузера. Картинка появляется в чате, доступна для открытия и скачивания и переживает перезагрузку страницы. Неоднозначный сбой не повторяет платную генерацию автоматически; для новой генерации кнопку нужно нажать снова. Максимальный размер PNG — 32 МБ.

Для генерации изображения API должен поддерживать function calling с `tool_choice` и endpoint `/images/generations`. Не все прокси поддерживают эти возможности.

GitHub Pages размещает статические файлы и не проксирует запросы. LLM API, Tavily и Jina должны быть доступны по HTTPS и разрешать CORS для источника сайта, например `https://<username>.github.io` (без пути репозитория). Для запросов с ключом сервер должен отвечать на preflight `OPTIONS`, разрешать методы `POST, GET, OPTIONS` и заголовки `Authorization, Content-Type`. Если конкретный сервис или провайдер не разрешает браузерные запросы, понадобится его браузерный шлюз или свой прокси; это нельзя исправить настройкой статической страницы.

## Возможности и данные

- Потоковые ответы, Markdown, таблицы, подсветка и копирование кода.
- Создание, поиск по сообщениям, переименование и удаление чатов.
- Редактирование вопроса с заменой последующей истории, повтор последнего ответа, экспорт текущего чата в Markdown.
- Адаптивный интерфейс, тёмная и светлая темы. На компьютере Enter отправляет сообщение, Shift + Enter добавляет строку; на телефоне отправка кнопкой.
- Чаты, черновики и настройки хранятся в `localStorage` данного сайта. Они не синхронизируются между устройствами и удаляются при очистке данных сайта. Нативная SQLite-история автоматически не переносится.
- По умолчанию ключ хранится в `sessionStorage` до закрытия вкладки. Опция **Запомнить ключ** сохраняет его в `localStorage` без шифрования. Ключ не попадает в сборку, репозиторий или экспорт чата.
- HTML из ответов не исполняется. Изображения из Markdown отображаются ссылками.
- В веб-версию не входят локальные агенты, доступ к файлам, RAG, Git, терминал и выполнение команд. Python используется только для расчётов, обработки данных и графиков в изолированном браузерном окружении.

Веб-версия предназначена для обычного общения, веб-исследования, Python-расчётов и генерации изображений.

## Проверки

```powershell
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

Тесты используют локальные подмены API: платные запросы и реальные ключи не требуются. Браузерные проверки покрывают потоковые ответы, контекст, ошибки, отмену, редактирование, повтор, копирование кода, историю после перезагрузки, мобильное меню, темы и загрузку из подпапки.
